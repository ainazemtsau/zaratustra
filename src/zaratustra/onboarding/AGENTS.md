# Public onboarding coordinator

This installed coordinator composes public Core, entry, process_creation,
process_change and process_packs surfaces. It owns readable prose adaptation,
truthful stage rendering and one recoverable explicit later-Work plan. Its files
grant no authority; Core records/history/receipts and exact content remain the only
committed facts. It never contacts providers, authors a Process definition, selects
a historical Work, creates automatically or imports development fixtures.
