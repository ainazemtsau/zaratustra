# Web exchange

Use public journal/Core operations; no second canonical database. The web client
writes free-form requests only. Capture preserves their exact UTF-8 bytes and
transport identity; parsing never grants authority. Agents interpret meaning and
account for independent items. Code validates scope, exact references, revisions,
attachments and replay. Original input is never replaced by the interpretation.
The owner chooses repository storage for complete portable Home data. The selected
web packet is optional discussion context; it is not a storage or backup restriction.
No history/context expansion through links, automatic polling, provider execution,
model routing or private installation changes. Native and fictional checks are not
evidence of a real owner ChatGPT/GitHub transfer.
