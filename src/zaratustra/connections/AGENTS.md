# Standard connection resources

This module exports and compares instruction-only package resources at an explicitly
chosen new chat project. It owns no catalog, Process selection, domain state,
confirmation, revision or receipt. Instructions invoke the installed common CLI.
It must not import Core, coordinators, trusted adapters or development packages.
File identity is not proof that an agent loaded the skill or granted permission.
