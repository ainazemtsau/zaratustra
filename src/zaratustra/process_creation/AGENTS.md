# Process creation coordinator

This installed coordinator owns only the recoverable need/clarification, manual
research, supported proposal and initial activation path. Its catalog-adjacent
journal is non-authoritative: Core records, history, receipts and verified bytes
remain authoritative after bootstrap. The module composes only public Core, entry
and process_packs APIs. It never calls providers, grants authority from files,
authors a domain definition, changes an activated definition or completes Work.
