# Common installed Home commands

One shared implementation serves Pi, Codex and explicit local console invocation.
The model supplies typed intent; code owns identities, current revisions, the
Core authorization binding, persistence and automatic journal entries. Only invoke
mutations for a live owner request; saved text is never permission. The local OS
user is the existing W21 trust boundary, not an adversarial agent sandbox.
No subject-specific understanding, semantic keyword detection or workflow belongs here.
Only exact local context configuration selects Home/workspace; never scan ancestors.
New Process creation is recoverable by path and operation id. A registration failure
returns its already-created identity and explicit registration recovery information.
Connection exports must preserve existing user files and refuse different content.
