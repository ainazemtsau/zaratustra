# Trusted local-agent tool adapter

`run_trusted` is the accepted W21 local-chat application seam. A trusted local host
that actually received the owner's instruction supplies its live decision callback,
actor and source reference; the adapter binds each exact displayed operation to the
existing in-process authority object. `zara-agent` is the closed common-host entry for
an explicit selected read or an explicitly requested prose creation draft. It may
authorize only the exact prepared read query; it has no activation, Process-change,
material or generic mutation command. The stdio MCP server is one optional elicitation
transport for those other operations. Saved state and prior authorization never grant
permission. No SQL, router, scheduler or development fixture belongs here.
