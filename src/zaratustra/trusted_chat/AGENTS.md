# Trusted local-agent tool adapter

`run_trusted` is the accepted W21 local-chat application seam. A trusted local host
that actually received the owner's instruction supplies its live decision callback,
actor and source reference; the adapter binds each exact displayed operation to the
existing in-process authority object. `zara-agent` is the closed common-host entry for
an explicit selected read, an explicitly requested prose creation draft, or the exact
activation of one saved proposal after a genuine current conversational decision.
Activation uses a read-only proposal/target preview first; its assistant-held digest
binds the later command to that shown intent before Core bootstrap begins. It has no
Process-change, material or generic mutation command. The stdio MCP server is one
optional elicitation transport for those other operations. Saved state and prior
authorization never grant permission. No SQL, router, scheduler or development fixture
belongs here.
