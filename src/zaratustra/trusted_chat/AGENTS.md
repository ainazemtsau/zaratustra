# Trusted local-agent tool adapter

`run_trusted` is the accepted W21 local-chat application seam. A trusted local host
that actually received the owner's instruction supplies its live decision callback,
actor and source reference; the adapter binds each exact displayed operation to the
existing in-process authority object. The stdio MCP server is one optional elicitation
transport over that API, not the permission semantics of every agent. MCP arguments,
files, model text, saved state and prior authorization never grant permission. It
stores no authorization and never falls back to a console. The CLI owns the separate
console fallback. No SQL, router, scheduler or development fixture belongs here.
