# First-use coordinator
This installed coordinator joins public Core, entry-catalog and intake operations.
It may bootstrap only an explicitly selected workspace, retain one non-authoritative
exact plan, and apply its fixed standard Core requests with separately supplied
trusted authorizations. It never grants authority, binds a Pack, invents domain
rules, refreshes an external request basis, contacts a provider or completes Work.
Request packages contain bounded authorized Core context and technical fields made
by the product. Format 2 adds only an all-or-nothing readable UTF-8 rendering derived
from those exact context bytes; format 1 stays valid for receive/recovery. Returned
text remains untrusted and goes through public intake.
