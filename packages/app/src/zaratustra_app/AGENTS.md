# Restart application

Uses public zaratustra_core only. Owns context composition, executor coordination, CLI and Pi transport. No SQL or legacy runtime imports. Scripted execution is transport evidence only. Explicit data-root and isolated Pi profiles; no paid fallback.

Package C adds versioned generic Sleep instructions and ordinary current-memory
admission. Public Sleep entry resumes committed launch windows and retained
terminal before new inference. Known invalid terminal remains known; explicit
refresh creates a new bounded Attempt. Semantic evaluation tools using official
Codex Luna are test-only and are not an installed Codex adapter. Pi live access
requires explicit endpoint/model/credential_env; no automatic fallback or OAuth
extraction. Credentials stay in server transport, outside model context/evidence.
