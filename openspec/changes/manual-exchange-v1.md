# Общий ручной обмен с внешними инструментами, версия 1

Основание: уточнение владельца 2026-10-05. Выбран ручной обмен как первая версия.
Это функция устанавливаемого продукта, применимая к выбранным Activity/Work
любого экземпляра. Настройки конкретного ChatGPT Project остаются данными экземпляра.

## Путь пользователя

1. Выбрать Activity и при необходимости Work; назвать внешний инструмент.
2. Получить копируемые инструкции и текущий выбранный контекст. Подготовленный
   документ сохраняется в Core как Handoff с точными адресами оснований.
3. Обсудить вопрос во внешнем чате и принести полный текст или явно выбранный файл.
4. Сохранить оригинал как Source с происхождением, областью, хешем и ревизией.
5. При уточнении того же материала сохранить новый неизменяемый Source со ссылкой
   на точный предыдущий Source. Старый оригинал доступен после нового процесса.
6. Разбор, изменение кода, принятие результата и выпуск выполняются отдельно.

## Общая поставка

- Python public surface в `zaratustra.pi_adapter`, устанавливаемый wheel.
- Обычный Pi: `zara_transfer` с prepare/import/read.
- Model-free CLI: `zara-core exchange prepare/import/read`.
- Шаблон имеет явную версию и поставляется вместе с кодом.
- Конкретные имена Activity, владелец, пути ZT и его история не входят в шаблон.
- Контекст содержит выбранные Activity/Work; чужие направления, материалы и
  содержимое репозитория не собираются автоматически.
- Свободный входящий текст сохраняется без требования JSON и без сокращения.
- Handoff prepared не означает фактическую отправку или внешний успех.
- Общая функция готова технически только после проверки исходников, wheel,
  второго тестового направления, точных версий и нового процесса.

## Граница разработки

Общий функционал разрабатывается в исходном репозитории: src, tests,
эта спецификация и пакет установки. Документ настроек одного экземпляра не
заменяет реализацию общей функции. Работа ведётся локально; удалённая публикация
и платный API не выполняются. Приёмка остаётся действием владельца.
