# E2 exact decisions and controlled actions

E1 base: `0b45c0853d7ee0c2f3c294b9bc4dd9803117462a`. Independent limited-E1
PASS and coordinator technical acceptance are separate from Anton's personal use/T31.
The E2 executor read the complete unchanged specification, checked both normative
digests and the actual E1 review/transfer, then waited read-only until the coordinator's
acceptance JSON became accepted for that exact SHA with E2 writes allowed.
The current assignment authorizes E2 implementation/public installation, not acceptance
of its eventual result. E3, full E/R1/T31, Sleep and Codex stay open.

Connected merges read latest staged values while independently guarding persisted
before revisions. This specifically closes reviewed H1 (silent overwrite of an earlier
approved correction). Shared pure alias generation prevents domain/display divergence;
a finite sequential formatter projection shows the actual corrected merge destination,
without validating, authorizing or executing changes. Staged restricted visibility flows
through chains. Final Activity state cannot leave/introduce current Work in a merged
source elsewhere in the batch. Duplicate update/catalog and overlapping Work mutations
remain honest atomic validation failures; no generic composition DSL is added.

Core remains portable TypeScript without Pi types; storage is behind StoragePort and
adapter imports use public index.ts. No database transaction spans a model, human or
external-tool wait. Working records and search are English; original bytes/names/quotes
and user-language decision explanations are preserved as such.

Every managed file has an exact Work/step/plan association where supplied or an explicit
model explanation of independent new action. Future restore must reconcile **every**
resumed potentially effectful Work/step even if the backup predates all intents/receipts.
E2 supplies epoch bindings and addressable attempts; no restore barrier is implemented.
Future archive/delete must also invalidate canonical export status, not bless an old file.

No dependency or license change. Existing pinned Zod/SQLite/Pi and parsers are reused.
The braces development advisory remains separate; runtime audit is not a Pi-host audit.
The supported profile is one trusted local writer, with no unconsented routing extension.
Synthetic SDK/RPC qualification is not actual owner testimony or T31.
