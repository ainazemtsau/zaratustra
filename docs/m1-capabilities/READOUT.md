# Семь ответов Process из одного разрешённого состояния

Техническая реализация T3 готова к свежей проверке и приёмке. Один запрос возвращает
статус, внимание, открытые решения, доступные и заблокированные работы, важные
результаты и требования к контексту выбранной работы.

| Вымышленный пример | Что получилось |
|---|---|
| Готовая Work, revision 7 | Она доступна; открытых вопросов и завершённых Results нет. Контекст возвращается после отдельного точного разрешения. |
| В metadata добавлен вопрос выбора, revision 8 | Эта же Work попадает в заблокированные и в открытые решения с причиной. Всё относится к одной revision. |
| Принят Result и создана следующая Work, revision 10 | В разрешённом обзоре обеих Works виден заголовок Result. Контекст следующей Work включает его законно унаследованные основания. |
| Обзор ограничен только следующей Work | Список Results пуст; скрытая предыдущая Work и её счётчик не раскрываются. Контекст с отдельным разрешением может включать точные унаследованные основания. |
| Нет разрешения или права отозваны | Ответы содержат отказ без значений, ids и counts. |
| Нет точного пакета/адаптера, запрос устарел или bytes недоступны | Явная недоступность; она не выдаётся за пустой список. |

Контракт сообщает состояние на момент чтения. Сохранённый ответ не разрешает
действие и после изменения состояния требует нового чтения. Metadata-доступ
не даёт права получить содержимое или записать Result.

Проверки: **204 теста PASS**, сборка, типы и шесть ограничений импортов.
Прежние 173 теста сохранены; добавлена 31 проверка границ чтения. Отдельный
воспроизводимый сценарий сохранил запросы, точные ответы, confirmations,
state/history и восстановил backup в новую папку с повтором настоящего Result.
