## Confirmed cause and missed coverage

An exact typed DataReference can address an ordinary retained Artifact. Relation
admission already allowed it. Memory composition then searched only knowledge
revisions for its checksum and falsely reported that the definition disappeared.
Rechecking the current membership of an older saved procedure snapshot therefore
blocked context preparation after a later entry referenced a valid input Artifact.
This was not loss of that original or a model/provider failure.

The prior package tested direct mixed material inputs and knowledge-to-knowledge
typed relations. It did not test this transitive combination or its appearance
after a procedure snapshot had already been saved. That gap belongs to the
implementation and validation, not the user.

The same assumption also existed in cache rendering, final availability checks,
full-history traversal and provider-admission checks of copied originals. During
the corrected native trace, the first query succeeded but the next send was
blocked by the latter check (`Memory basis disappeared`); this was fixed before
delivery. No failing trace is counted as a passing path.

  checks correspondence with indexed edges. Mismatch fails; it never grants a

  closure retains the existing identity. Current-mode relations stay knowledge-only.

  fallback skips a missing dependency or fabricates an original.
