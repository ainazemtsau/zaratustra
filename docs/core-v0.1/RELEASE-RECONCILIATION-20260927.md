# Сверка первого рабочего ядра, 2026-09-27

Источник: `Zaratustra_Core_Specification_v0.1.md`, AD01–AD08, Q10 и
сквозной критерий V1. «Работает» здесь означает наблюдаемый программный путь
в установленном синтетическом пространстве, а не содержательную приёмку.

| Требование | Действующая возможность | Пользовательский вход | Оставшаяся работа |
|---|---|---|---|
| Пространство, идентичность, права | Отдельный SQLite store; текущие Decision/Grant, квитанции, история, явная schema 12 | `zara-core setup/verify/upgrade`, Pi | Приёмка владельцем и реальные данные отдельно |
| Обычный Pi, разговор, инструменты | Поставляемое расширение и нативные `read/write/edit/bash`; Core bridge и наблюдаемые вызовы provider | `zara-core run` | Качество реальной модели проверяется при использовании |
| Activity/Work/Method | Создание, ревизии, составной план, независимые Attempt и ресурсы | `zara_development`, `zara-core assign` | Содержательная оценка организации остаётся пользовательской |
| Вопрос, продолжение, результат | Адресное ожидание и ответ, сохранённый output, отдельное принятие или закрытие | `/zara-answer`, `zara_development`, `/zara-accept` | Реальное качество результата не доказано синтетической пробой |
| Память и документный handoff | Source/Claim/Analysis/View, ContextManifest, адресная передача и возврат | `zara_memory` | Практическая достаточность определяется использованием |
| Sleep | Ограниченная пагинация и курсоры; доставка двух источников, анализ, остаток и оба принятых дочерних Work; отдельное принятие родителя. Финальный установленный проход зафиксировал отсутствие независимого периода без ложного сравнения | `zara_sleep`, обычный Pi | Смысловая полезность и глубокая полнота разбора не удостоверяются инженерной пробой |
| Изменение Method/Binding | Кандидат, план/результаты, Decision/Grant, trial/regular, применение, остановка и возврат | `zara_development.apply` | Наблюдение поздней полезности остаётся текущей работой |
| Программный и составной Change AD05 | Типизированный Program build с SHA/ArtifactRef/resource/path, обязательная проверка, допуск, атомарный пакет с Method/Binding, физическая установка с подтверждением байтов, stop/restore | Pi создаёт Candidate/Decision; `zara-core change-install/stop/restore` | Возврат прежней версии требует действующего допуска; при его отсутствии фиксируется `partial`, а не ложный успех |
| Перестройка Activity AD01/Q10 | Типизированный ActivityChange проходит Candidate/ValidationPlan/Decision и атомарный split/merge; stop и точный допустимый restore сохраняют историю. Обычная поправка доступна напрямую | Pi `zara_development.apply`; прямой `reorganize_activities` для малой коррекции | Decision/Grant/Binding не копируются автоматически: для их изменения нужны отдельные адресные операции, обозначенные в disposition |
| Установка и запуск | Wheel вне checkout, закреплённые Python 3.13.7/SQLite 3.53.3/Pi 0.87.0, выбранные space/workspace/provider/model | `uv pip install`, `zara-core setup/run` | Иные OS/runtime не заявлены |
| Обновление и возврат программы | Явный backup перед schema upgrade; восстановление в новый каталог/epoch; `select` проверяет всю исходную историю операций | `upgrade/backup/restore/recover/select` | Старый wheel без поддержки schema 12 не запускается. Возврат к нему с сохранением новой истории недопустим; нужен совместимый выпуск |
| Внешний ремонт | Pulse плюс адреса неизвестных assignment/invocation и открытых ожиданий; отдельные inspect, DELETE, backup/restore/recover | `zara-core repair` без модели | Неизвестный внешний исход требует внешнего свидетельства, ядро его не угадывает |
| Pulse | Read-only ограниченный checkpoint, изменённые записи, зависимости и прежние открытые адреса | `zara-core pulse --previous-report` | Ручной запуск предусмотрен спецификацией |

Специальный Dream, постоянный scheduler, второй provider и гарантия
семантической пользы исключены либо отложены самой спецификацией. Проверки
состава не заменяют решение владельца о выпуске и реальную оценку пользы.
