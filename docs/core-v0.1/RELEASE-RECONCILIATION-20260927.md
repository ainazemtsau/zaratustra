# Сверка первого рабочего выпуска, 2026-09-27

Источник требований: `Zaratustra_Core_Specification_v0.1.md`, прежде всего
«Сквозной критерий готовности V1», AD01–AD08 и матрица покрытия. Статус ниже
означает наличие программного пути, а не приёмку владельцем или проверку
смысловой пользы.

| Требование | Действующая возможность | Пользовательский вход | Остаток |
|---|---|---|---|
| Локальное пространство, идентичность и права | SQLite space, Decision/Grant, точные квитанции и ревизии | `zara-core setup`, обычный Pi | Старая схема обновлена в установленной синтетической пробе; приёмка реальных данных отдельно |
| Обычный Pi и свободный разговор | Поставляемое расширение, Core bridge, наблюдаемый Provider, первичка и ContextManifest | `zara-core run` | Качество реальной модели выясняется в использовании |
| Activity, Work, Method | Core операции и доступные в Pi `zara_development.apply` | Обычный Pi | Перестройка Activity с сохранением принадлежности, происхождения и начатых Work отсутствует |
| Составная работа и независимые Attempts | План, дети, обязательства, ресурсы, назначение, вопросы, продолжение | Pi `zara_development.apply`, `zara-core assign`, `/zara-answer` | Проверить перенос результата между частями в полном пользовательском сценарии |
| Раздельный результат и принятие | Предложенный результат, отдельные Core операции принятия | `zara_development.apply` | Выполнить принятие в установленном сценарии отдельно от записи |
| Память и текущий контекст | Source/Claim/Analysis/View, адреса, FTS, доставка manifest | `zara_memory` и `/zara-*` | Практическая достаточность требует использования |
| Документный handoff | Адресный документ, передача/возврат с отдельными статусами | `zara_memory` | Внешняя доставка вне подключения остаётся наблюдаемой лишь по подтверждениям |
| Sleep | Исходный Method, Work, ограниченное перечисление и сохранённые курсоры/эффекты | `zara_development.start_sleep`, затем обычный Pi | Проверить полный установленный сценарий после исправления последней страницы |
| Изменение Method/Binding | Candidate, Plan/Result, Decision, trial/regular, stop, restore | `zara_development.apply` | Программная цель и составное применение отсутствуют |
| Программная возможность AD05 | Development Work может записать реальный файл ресурса | Pi `write`/`edit` в назначенном Work | Нет типизированного build/patch, проверки, допуска, установки, подтверждения доступности и возврата как одного согласованного Change |
| Перестройка Activity AD01/Q10 | Можно создать и исправить Activity, Work хранит исходную принадлежность | `zara_development.apply` | Нет split/merge/reparent с сохранением происхождения и текущих поручений |
| Установка и запуск | Wheel, `zara-core setup/run`, выбранные пространство, ресурс, actor, Pi/SQLite/provider | `uv pip install` и `zara-core` | Чистая установка вне checkout проверена; другие конфигурации не заявлены |
| Обновление и возврат программы | Явная Core schema migration; `zara-core upgrade` с backup; restore/recover/select | `zara-core upgrade`, `restore`, `recover`, `select` | Обновление wheel и текущей схемы проверено; возврат к несовместимой старой схеме без потери новой истории не реализован и блокируется |
| Ремонт без модели | Pulse, receipts, recovery, backup/restore, managed deletion | `zara-core pulse/repair/backup/restore/recover` | Адресный ремонт иных структурных ошибок пока сводится к инспекции и штатным операциям |
| Pulse | Read-only changed-since-checkpoint, зависимости, прежние адреса, структурные находки и наблюдения | `zara-core pulse --previous-report` | Сохранённый checkpoint и восстановленное пространство проверены; регулярный запуск не обязателен |

Обязательные строки с остатком нельзя считать реализованными по наличию одного
Core API, записи статуса или отдельной тестовой пробы. Специальный Dream,
постоянный scheduler, второй provider и доказательство практической пользы
явно исключены либо перенесены самой спецификацией.
