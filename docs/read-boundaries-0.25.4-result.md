## Confirmed original behavior

The installed 0.25.3 reproduction retained all addressed bytes but exposed an
incorrect reader for ordinary Artifact inputs. Four runtime query contracts
advertised definition-local bindings that execution rejected. Punctuation in a
normal text query reached raw FTS5 grammar. The disposable reproduction changed
zero Core revisions and used zero real model calls.

Native 0.25.3 HTTP, TCP and SSE trials each made three actual localhost sends:
one tool/result, one failed send and one native automatic retry. Context hooks
ran again on retry. The TCP retry could lose its original selected execution.
A separately injected mandatory-context refusal produced zero additional HTTP,
but the visible provider error replaced the first refusal with a generic
ContextManifest-readiness message. These are current reproductions, not proof of
every cause in earlier private transcripts.

## Implementation

- Public material navigation and exact fragment readers use current rights and
  transitive source checks. Existing reference/state JSON stays compatible.
- New executable selectors omit definition-local aliases. All four operations
  use the common admission boundary; saved definitions keep their old semantics.
- Exact mixed material batches are bounded reads with explicit continuation;
  indexed selections and caches retain their existing identity and history.
- Text search is literal by default. Advanced FTS5 is explicit; continuation is
  bound to the original query and mode. Empty results state index coverage.
- Native provider refusal preserves its first context error. Same-origin retry
  after unknown response rechecks the exact durable delivery and stops before
  HTTP. A fresh owner request can explain saved state without replay/acceptance.

See [interface documentation](read-boundaries.md) for contracts.
