Existing registered relations now resolve exact Method and supporting review endpoints
through the same guarded/access-checked resolver; no parallel graph engine is introduced.
Run outcomes can pin changed domain/supporting records, while invocation outputs must be
retained Evidence. Work context exposes a newer Method warning without rewriting its old
context ref, so discovery can choose the current version and past applications stay exact.

All newly linked records, supporting rows, refs, versions, indexes, Changes and receipt
commit together. Prepared intents remain recovery metadata. No transaction spans a model,
tool, user or external wait. Pi keeps its system sections and request-local snapshot;
the adapter replaces only its own snapshot and never appends permanent snapshot messages.
Environment is observed package/resource hashes, bootstrap/skills, provider/model, Node,
platform and available thinking setting; unavailable harness version/temperature stay null.

No dependency was added. Runtime libraries retain their pinned versions/licenses. Pi,
SQLite/FTS, Zod and existing parsers provide the underlying mechanics. The known braces
development advisory stays separate and open. No installer, planner, ORM, embeddings,
reranker, second LLM, authorization platform or method executor is introduced.

Next bounded outcome is E2: exact confirmations and controlled actions/unknown-result
recovery, including managed SKILL.md export/drift. E3 retains backup, quarantine restore
and storage lifecycle. No generated executable skill/script/extension publication in E1.
