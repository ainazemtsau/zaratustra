# ADR-0001 — Accepted stack and setup packaging
Status: setup mechanics selected by executor within the accepted plan; no new owner verdict.

The owner-approved plan §27 names Python 3.13, uv, sqlite3, Pydantic v2,
pytest, ruff and SHA-256. This setup preserves them and adds the Python
profile's development tools mypy and import-linter.
Use src/zaratustra/{core,cli} as one installable package, with uv_build 0.8.22
matching the installed uv. This avoids a second runtime/build system and a
list of separately packaged modules. Version 0.0.0 denotes scaffolding.
Managed Python 3.13.7 is selected explicitly; the lock pins dependency versions.

The profile's package=false/PYTHONPATH default would not produce an installable
product. The setup CALL explicitly requires packaging compatibility, so use a
build backend and verify a wheel outside the checkout. No product CLI, DB or
workspace is implemented. W26 remains open for actual user installation.
Other W19–W27 remain unresolved. No speculative modules beyond Core/CLI.
