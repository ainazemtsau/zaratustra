# Обсуждение в ChatGPT → обработка в Pi

Кандидат 0.21.0, 17 сентября 2026. Личная установка владельца не обновлена.

## Как пользоваться после подключения

1. В Pi: «Подготовь для обсуждения в ChatGPT наше предложение о выборе моделей.
   Включи относящиеся решения и текущий вопрос». Агент готовит выбранный материал.
   Передача содержания в GitHub — по указанию владельца. История всего процесса
   автоматически не передаётся.
2. В Project ChatGPT обсуждаете вопрос. Для первого подключения Pi готовит
   инструкции Project; владельцу не нужно придумывать поля или JSON.
3. В ChatGPT: «Сохрани это как запрос: идею в бэклог, а отчёт приложим отдельно».
   Если подключение умеет создавать файлы, ChatGPT сохраняет обычный текст и
   показывает ссылку. Само сохранение не запускает разработку.
4. В Pi: «Обработай входящие». Агент читает оригинал, сохраняет понятные результаты,
   уточняет неоднозначности и запрашивает отсутствующие файлы по именам. Ошибки
   оформления текста не требуют от владельца исправлять формат.
5. В следующем чате: «Продолжим разбор входящих. Вот запрошенный отчёт». Агент
   сохраняет файл без пересказа и продолжает с сохранённого состояния. Ещё один
   новый чат может открыть результат и показать, что осталось незавершённым.

## Что показано работающим

В отдельном учебном Home настоящий Pi прочитал заранее полученный запрос с
испорченным JSON и обычным русским текстом. Сохранил идею как неутверждённое
предложение, запросил «Сравнение моделей.md» и оставил запрос открытым. В новом
чате получил файл, сохранил его точные байты и завершил запрос. Третий новый чат
открыл основания и подтвердил итог: запросов не осталось, разработку не начинали.
Независимая проверка через публичный API подтвердила побайтное совпадение файла.

Это проверка работы Pi и продукта. Учебный запрос был внесён локально, поэтому
показ не доказывает реальную передачу из аккаунта ChatGPT через GitHub.

## Перед личным использованием

Нужно отдельно проверить возможность записи файла из выбранного ChatGPT Project
в личный приватный репозиторий. Локальная авторизация GitHub этого не доказывает;
инструкция Project не добавляет отсутствующий инструмент записи. После проверки
канала личное обновление и подключение выполняются отдельным согласованным шагом.

Файлы, созданные в ChatGPT, владелец пока передаёт Pi по запросу. Автоматического
скачивания вложений, маршрутизации моделей и фоновой обработки здесь нет.
