# Приёмка тестового смысла T4 и граница установки

2026-09-10, фактические слова владельца в авторской задаче:

> Но если только протестировать, так если, ну, тесты все прошли, если он прошёл, то окей, я этот шаг принимаю.

На уточнение, допустим ли выдуманный пример в тестах разработки при исключении
из устанавливаемого продукта и пользовательских данных, владелец ответил:

> В тестах разработки можно; в продукте и моих данных — нет

Принимается проверочный смысл первого выдуманного Process, с указанной границей.
Исполнитель обязан подтвердить исключение примеров из новой устанавливаемой
сборки. Слова владельца не заменяют технические проверки и не означают Direction
close T4/M1. Существующие пользовательские установки и данные не исследуются.
