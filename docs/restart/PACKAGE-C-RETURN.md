## Implementation and boundaries

Attempt and versioned data progress record; no SleepRun, competing current,
private SQL client or second memory store. Core stays independently installable;
app imports only public Core. No legacy runtime or user-data migration.

`Sleep.start` installs generic `sleep/1` only when absent, opens a finite ordinary
Work and finishes interrupted launch commits. `run` recovers retained terminal
before inference. Explicit refresh permits a new Attempt after a known invalid
response, preserving old bytes and reservation.

`read_history` enumerates immutable record revisions, actual Work outcomes, raw
human input and retained Attempt observations, including unknown/error without
C8. Each source has event sequence, index and SHA-256; scope and pinned method,
inputs/raw messages accompany outcomes. A high watermark stays fixed through
pages. Later arrivals remain available to a later pass.

Formal progress contains every §7 field: distinct enumeration, selection, delivery,
claimed analysis, exploration coverage, remainder, receipts, reservations and
unresolved calls. Preparation or unknown send does not establish delivery.
Analyses are ordinary retained data with exact sources and free content; they
remain model claims. Code does not judge questions, alternatives, truth or value.

Ordinary `Coordinator.open_work` reads current applicable active memory and the
chosen scoped Method; admission rechecks pinned current roles. Free text/object
records remain valid. Active/proposal/withdrawn status is separate metadata.
Non-human memory/Method mutation needs explicit kind/scope delegation; C3/C8 share
those checks. Rollback creates a new revision and preserves prior bytes. Actual
