## instructions

2. Confirm the bench identifier from the note. If it cannot be confirmed, state that explicitly rather than guessing.

4. List the next physical check indicated by the note; state explicitly if it is not specified.
5. State missing information.
6. Return a short checklist addressed to the retained source note.
